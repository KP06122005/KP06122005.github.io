# Portfolio: Krishna Prashanth Paulpandian

Static site (HTML + CSS + JS, no build step). Deploy with GitHub Pages.

## Deploy
1. On GitHub, create a **public** repo named `KP06122005.github.io`.
2. Upload everything in this folder (keep `assets/` and `.nojekyll`).
3. Repo **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, folder `/ (root)`. Save.
4. After 1–2 minutes the site is live at **https://KP06122005.github.io**.

## Update
- Text and projects: edit `index.html` (the `P` and `R` arrays near the bottom hold project and paper entries).
- Resume: replace `assets/Krishna_Prashanth_Resume.pdf` (keep the same name).
- Photo: replace `assets/photo.jpg` with a square image.
